# 复赛 A 题独立工程

本目录用于复赛 A 题，和初赛工程完全分离。当前阶段仅完成目录骨架，尚未复制初赛代码、安装环境或运行模型。

## 目录结构

```text
fusai/
├─ data/
│  ├─ raw/                 原始数据，只读
│  ├─ processed/           可复现的数据处理产物
│  └─ splits/              固定训练集、验证集和留出集划分
├─ configs/                三个回归任务和模型配置
├─ docs/                   方案、审计记录、实验协议和使用说明
├─ src/                    可复用的数据处理、评价和建模模块
├─ scripts/                可执行的审计、训练、评估和报告脚本
├─ tests/                  自动化测试
├─ outputs/
│  ├─ tables/              指标、特征和审计表格
│  ├─ figures/             图表
│  ├─ predictions/         交叉验证和最终预测结果
│  ├─ models/              复赛训练好的模型
│  └─ logs/                实验日志和历史运行记录
├─ submission/
│  ├─ model/               提交用模型和调用代码
│  └─ results/             提交用预测结果
└─ paper/
   └─ materials/           论文使用的图表和证据材料
```

## 复赛任务

- 任务一：使用非睡眠类特征预测 `Sleep Quality Score`，评价指标为 (R^2)。
- 任务二：预测 `Productivity Score`，处理多重共线性，评价指标为调整 (R^2)。
- 任务三：使用有效特征预测 `Health Score`，评价指标为 (R^2)。

后续工作从数据审计和特征契约冻结开始，再进入基线回归、模型比较、最终模型冻结和提交包制作。

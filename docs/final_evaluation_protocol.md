# 复赛最终评估协议

本协议连接三个已经冻结的开发集候选与后续一次性内部留出集评估。协议建立时不读取留出集标签，也不训练最终模型。

## 1. 当前冻结状态

- 任务一、任务二、任务三均已完成开发集候选选择。
- 三个任务使用同一份固定样本划分：8000条开发集、2000条封存留出集。
- 开发集固定为五折，每折1600条；留出集的 `cv_fold` 固定为 `-1`。
- 三份候选清单均记录 `holdout_evaluated=false` 和 `final_model_trained=false`。

## 2. 最终评估顺序

1. 依据冻结配置实现三个完整评估模型。
2. 只使用8000条开发集训练评估模型。
3. 完成保存—加载—预测一致性、原始字段预测、必需字段和模型哈希测试。
4. 在模型文件及其哈希冻结后，由人工提供精确确认口令，一次性评估2000条留出集。
5. 留出集结果只用于内部最终评估和论文结果报告，不得用于重新选择特征、模型或参数。

## 3. 指标口径

- 任务一主指标为R²，辅助指标为MAE和RMSE。
- 任务二主指标为按冻结工程字段口径计算的调整R²，辅助指标为R²、MAE和RMSE。
- 任务三主指标为R²，辅助指标为MAE和RMSE。
- 开发集OOF、内部留出集和组委会隐藏测试集结果必须分开标注。

## 4. 留出集门禁

- 留出集只允许评估一次。
- 评估脚本必须要求与配置完全一致的确认口令。
- 确认口令不得模糊匹配或自动补全。
- 评估前必须验证数据、划分、候选配置和候选清单哈希。
- 留出集评估完成后必须将消费状态写入不可变运行清单。

## 5. 论文材料人工暂停门禁

在进入论文表格、论文图片和论文证据索引代码阶段之前必须停止执行并提醒用户。未经用户再次明确确认，不创建、不修改、不运行下列内容：

- 论文表格生成代码；
- 论文图片或制图代码；
- 论文证据索引生成代码。

该门禁记录在 `configs/final_evaluation_protocol.toml`，并由自动化测试校验。
